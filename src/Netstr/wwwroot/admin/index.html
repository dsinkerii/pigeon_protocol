🌐 Network, IP Binding & Server Ports
📡 Router & Local Network (LAN) Connectivity
• To access the relay and panel from other devices on your router (e.g., http://192.168.88.31:8083), set Listening Host to 0.0.0.0.
• If set to 127.0.0.1 or localhost, the relay only accepts connections from this physical machine and rejects local router traffic.
Listening Host / IP Binding ?Network interface IP to bind to. '0.0.0.0' binds all interfaces (enabling LAN/router access such as 192.168.88.31). '127.0.0.1' binds only to the local machine.
Key: Server.Host
Listening Port ?TCP port for HTTP, Nostr WebSockets, Blossom Media, and Web Panel.
Key: Server.Port
WebSocket Path ?HTTP route where Nostr clients connect for WebSockets. Standard default is '/'.
Key: Connection.WebSocketsPath
Allowed Hosts Header ?Host header filter for incoming requests. '*' allows all hostnames.
Key: AllowedHosts
Admin Web Path Prefix ?Base URL path for accessing the web admin panel. Default: '/admin'.
Key: Admin.Path
🔐 Authentication Policy & Protected Kinds (NIP-42)
Auth Mode ?Always: Must authenticate to read or publish.
Publishing: Anyone can read, only authenticated can post.
Optional: Accepts auth freely.
Disabled: No NIP-42 challenge issued.
Key: Auth.Mode
Protected Event Kinds ?Comma-separated list of event kinds that strictly require auth to subscribe/publish (e.g. 4 for Legacy DMs, 1059 for NIP-17 Gift Wraps).
Key: Auth.ProtectedKinds

Key: Limits.Events.MaxEventTags

Key: Limits.Events.MaxPendingEvents

Key: Limits.Events.MaxCreatedAtLowerOffset

Key: Limits.Events.MaxCreatedAtUpperOffset
